## Struttura del progetto

Il progetto si suddividerà nelle seguenti fasi:
- **Generazione dei dati**, in conformità al dominio di pertinenza, in questo caso le ***reti peritali***. Non avendo esperienza diretta in questo ambito i dati potrebbero essere generici o non perfettamente pertinenti.               ***Essi rappresentano solo un mezzo e non un fine*** per questo progetto. Si noti che si cercherà di generare dei dati il più realisticamente sporchi possibile.  Rimando alla cartella **data**
- **Definizione dei punti di analisi** che andranno ad essere analizzati durante questo progetto. 
        Questa parte è aperta a continui aggiornamenti, per rimpolpare il progetto e renderlo più completo possibile.  
        Troverete questa parte nell'apposito file in questo repo.
- **Analisi dei dati**,  opportunamente caricati su un DB mySQL locale. Troverete le vari query in uno o più appositi file in questo repo.
- **Insight e visualizzazioni**, in `[nome-file/cartella]`.
